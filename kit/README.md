# Kit de Pauta

Material de trabalho do contador. **Nada aqui é software** — são arquivos de
texto para você abrir ao lado, copiar, colar e editar. Foi feito para ser
mudado: troque as palavras pelas suas.

| Arquivo | Para quê |
|---|---|
| [`mapa-de-contatos.md`](mapa-de-contatos.md) | Para quando você acha que não tem para quem mandar |
| [`mensagens.md`](mensagens.md) | Para não travar na hora de escrever a primeira |
| [`modo-assistido.md`](modo-assistido.md) | Para a carteira que não clica em link |
| [`roteiro-de-conversa.md`](roteiro-de-conversa.md) | Para a reunião não morrer depois do "e agora?" |
| [`calendario-trimestral.md`](calendario-trimestral.md) | Para não acabar a carteira no mês 2 |
| [`placar.md`](placar.md) | Para saber se está funcionando sem montar relatório |
| [`divulgacao.md`](divulgacao.md) | Textos para redes, quando você quiser falar em público |

## As quatro regras que valem para tudo aqui

Elas não são estilo. Cada uma existe por um motivo, e quebrá-las estraga o
instrumento inteiro.

**1. Pergunta, nunca recomendação.**
Nada no kit conclui pelo cliente ou prescreve solução — nem "você precisa
cortar", nem "o ideal seria mudar de regime". Enquanto for pergunta, quem conclui
é ele, e é isso que faz ele querer a conversa seguinte. No instante em que vira
recomendação técnica ou tributária, deixa de ser diagnóstico e passa a ser
responsabilidade sua, de graça.

**2. Descrever, nunca qualificar.**
Fale da situação, nunca do profissional. "Saiu mais do que entrou" é
constatação. "Você está descontrolado" é julgamento — e ninguém contrata quem
acabou de julgá-lo.

**3. Sem vocabulário de venda.**
Não use "oportunidade", "não perca", "última chance", "solução completa". Você
está abrindo uma conversa técnica, não fazendo campanha. O leitor é seu cliente,
não um lead.

**4. A ressalva vai junto, sempre.**
> Este instrumento produz estimativa de caixa. Não substitui a apuração contábil.

Ela não é rodapé jurídico: é o que marca onde a ferramenta para e o seu trabalho
começa. Tirar a ressalva não deixa a mensagem mais forte — deixa você exposto.

## Como usar, na ordem

1. Abra o `mapa-de-contatos.md` e escreva vinte nomes. Só nomes, sem julgar se
   "cabe" ou não — isso vem depois.
2. Escolha cinco. Mande a mensagem do `mensagens.md` para esses cinco.
3. Quem não responder em três dias, vale o `modo-assistido.md`: você preenche
   junto, ao telefone.
4. Quando o cliente devolver o resultado, abra o `roteiro-de-conversa.md` no
   bloco do cenário dele.
5. Anote no `placar.md`. Uma linha por envio, nada além disso.
6. Daqui a três meses, o `calendario-trimestral.md` diz o que fazer com a mesma
   lista.

Cinco envios por semana, não cinquenta. O gargalo não é a lista — é a sua
capacidade de conduzir as conversas que vão nascer dela.
