# Placar

Para saber se está funcionando sem montar relatório.

Uma folha. Se virar planilha com aba, você parou de trabalhar a carteira e
começou a administrar o método.

---

## O que anotar

Uma linha por envio, no momento do envio. Trinta segundos.

| Data | Quem | Como (envio/telefone) | Respondeu | Conversa marcada | Virou trabalho |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

Só isso. Não anote o resultado financeiro do cliente aqui — além de não servir
para nada seu, é dado dele.

---

## Os três números do trimestre

No fim de cada rodada, conte:

1. **Quantos enviei.**
2. **Quantos responderam.**
3. **Quantas conversas aconteceram.**

E uma pergunta, que vale mais que os três:

> Das conversas que aconteceram, quantas eu não teria tido de outro jeito?

É a única medida que diz se o instrumento fez diferença ou se você só documentou
o que já ia acontecer.

---

## Como ler o placar

O erro comum é olhar para "quantos viraram trabalho" na primeira rodada e
concluir que não funciona. Não é aí que se lê.

**Se poucos responderam:** o problema provavelmente é a lista, não a mensagem.
Volte ao [`mapa-de-contatos.md`](mapa-de-contatos.md) e veja se você mandou para
quem tem motivo para falar com você.

**Se responderam mas não viraram conversa:** o problema está na sua resposta ao
resultado. Reveja a Parte 2 do [`mensagens.md`](mensagens.md) — quase sempre é
diagnóstico dado cedo demais, que fecha a porta em vez de abrir.

**Se as conversas aconteceram e não viraram trabalho:** isso pode ser normal. Nem
toda conversa vira contrato, e uma parte do retorno é o cliente que fica mais
tempo com você porque passou a ter um contato que não é cobrança de guia.

---

## Um lembrete sobre expectativa

Cinco envios por semana, um trimestre, é sessenta contatos. Se três viraram
conversa de verdade e uma virou trabalho, o método está funcionando.

Parece pouco escrito assim. Compare com o que aconteceu no trimestre passado,
quando o único contato com esses sessenta foi guia e prazo.
